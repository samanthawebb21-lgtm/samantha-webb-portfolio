# Samantha Webb — portfolio

A static portfolio for Samantha Webb's work in AI evaluation, model behavior, and technical operations.

The site uses plain HTML and CSS. It has no build step, JavaScript dependencies, analytics, or external font requests. GitHub Pages serves the files from the repository root.

Project 42 case-study links point to the separate [public research repository](https://github.com/samanthawebb21-lgtm/Project-42). Each portfolio brief distinguishes public results, local verification, historical documentation, and open questions.
